# Launch plan (LTX production profile)

## Relationship to the channel's existing launch

The channel itself is already live: `@explainedfromwithin` is claimed, brand
assets are generated, the **Inside Your Body** playlist exists, and the
sibling `sibling-repo` repo's LTX-2.5 profile has already produced and
scheduled its own EP001. None of that is repeated here. This document plans
**this LTX profile's own first episode** as an independent production run on
the same brand.

**Status (2026-10-29).** This profile's EP001 ("How Glass Bottles Are Made: Sand to Bottle, From the Inside", Inside Manufacturing) is closed and
awaits owner upload. The channel now has live pillar playlists for Inside Your Body, Inside Manufacturing and Inside Materials and a story engine
(`STORY_ENGINE.md`) that governs the next LTX episode. The text below is the original plan for EP001 and is kept as the record.

## First episode seed

No topic is pre-selected for this profile. `CHANNEL_STRATEGY.md`'s four
candidate questions (one per pillar) are the working shortlist; `01-ideation`
picks one — it is not required to avoid the LTX profile's already-shipped
tiny-cut/platelet topic, but re-researching the identical topic on a second
engine is unlikely to be the most useful use of this profile's first slot.
Whatever is chosen, do not stretch a single causal event over the full
runtime. The premise is written at `01` and factual scope is verified at
`02`/`02a`/`02b`.

Reason: the September 2026 Veo experiments (`PILOT_LESSONS.md`) already
exposed the central production problem for this format on any engine —
showing a clear causal interaction while retaining visual identity. Do not
count those experiments, or the sibling profile's LTX renders, as
evidence for this profile's own LTX-2.5 render quality.

## Bounded pilot sequence

1. Initialize the new episode and complete preflight.
2. Author one premise at 01, using whichever candidate the owner steers toward.
3. Research and source the mechanism before a script (Branch C ledgers, `SCIENCE_AND_SOURCING.md`).
4. Walk the existing script/references/planning/compiler stages one at a time.
5. Human-review the representative LTX-2.5 pilot set (`04h`) before rendering the remainder.
6. Assemble the complete long-form pilot at the active runtime and evaluate
   comprehension, pacing and whether every section adds explanatory value.

## Later tests

After a coherent first episode under this profile, test the remaining three
pillars with the same explorer and visual language. Each requires fresh
sourcing. Do not commission a multi-episode batch based only on attractive
samples.

## Record outcomes

- Generated attempts and accepted clips.
- Actual generation cost and production/editing time.
- Character and environment continuity failures.
- Whether a viewer can describe the intended mechanism without prompting.
- When published, retention, completion, repeat viewing and requests for another
  topic, interpreted against sample size and traffic source.
- Where relevant, how this profile's cost/time/quality compares with the
  sibling LTX profile's already-recorded numbers — a real, useful
  comparison this channel is unusually well positioned to make, precisely
  because both profiles share one brand.

No fixed success threshold or monetization prediction is claimed yet.
