# Episode Specification and QC

## Master specification

| Dimension | Target |
|---|---|
| Runtime | 8:00–11:00; target 9:30 |
| Format | 16:9, 24 fps |
| Speaking characters | 3–5; preferred 4 |
| Performance unit | 20 seconds, fixed |
| Dialogue pace | Approximately 135–150 spoken words per minute, adjusted for emotion |
| Evidence/reconstruction | 25–35% of runtime |
| Reversal | 5:15–6:30 in a 9:30 cut |
| Manual mid-roll opportunity | One natural transition after a completed evidence/reversal beat within 5:15–6:30; never mid-sentence or mid-action |
| Story out | Final runtime minus 20 seconds; 9:10 in the 9:30 target cut |
| Verdict/end screen | Final 20 seconds; 9:10–9:30 in the target cut |
| Verdict | Exactly two defensible options |
| Shorts | Two 25–45 second funnels per long-form episode |
| Master loudness | Signed Anyway target −14 LUFS-I ±1 LU; maximum −1 dBTP true peak |
| Audio delivery | 48 kHz stereo; dialogue passes phone, headphones and mono fold-down |
| Captions | Human-reviewed UTF-8 SRT matched to picture lock |

## Required episode package

- Approved script brief and final script.
- Character/prop reference manifest.
- Shot list with timing, speaker IDs, eyelines and continuity states.
- Clip prompt file, one continuous-prose prompt per 20-second clip.
- Evidence graphics source file.
- Draft renders and rejection log.
- YPP Authorship Evidence Pack required by `COMPLIANCE_GATE.md`.
- Final 4K or 1440p master plus 1080p upload mezzanine.
- Human-reviewed UTF-8 SRT captions, thumbnail, metadata and disclosure copy.
- Compliance sign-off and model-license evidence.

## Editorial QC

- [ ] Consequence appears within 10 seconds.
- [ ] Viewer understands the decision and scale by 0:45.
- [ ] No more than 25 seconds passes without a meaningful information or presentation change.
- [ ] At least one earlier clue supports the reversal.
- [ ] Every major character has a credible defense or moral claim.
- [ ] Ending does not tell the viewer which verdict is correct.
- [ ] Dramatic story concludes before the final 20-second verdict/end-screen period.
- [ ] The planned manual mid-roll slot follows a completed beat and does not interrupt dialogue, action or the reversal payoff; remove it if no natural break exists.

## Visual/audio QC

- [ ] Character identity, wardrobe, age and eyelines remain consistent.
- [ ] Speaking mouths match assigned dialogue; silent characters do not lip-move.
- [ ] Hands and hero props pass close-up inspection.
- [ ] All readable evidence text was built in post, not trusted to generation.
- [ ] Final program measures −14 LUFS-I ±1 LU with true peak no higher than −1 dBTP.
- [ ] Dialogue is intelligible on phone speakers, headphones and mono fold-down at a comfortable low volume.
- [ ] Room tone and loudness are continuous across clips; LTX-2.5 native audio has been conformed in post.
- [ ] UTF-8 SRT captions match final dialogue and speaker intent exactly.
- [ ] Speaker labels use `NAME:` only when the speaker changes off-screen or is visually ambiguous; meaningful non-speech cues use brackets, such as `[door locks]`.

## Packaging QC

- [ ] Title leads with the event/consequence and is 70 characters or fewer where practical.
- [ ] Thumbnail adds information, uses one focal point and no more than three words.
- [ ] Title/thumbnail do not imply a real event.
- [ ] Description opens with the case promise and includes disclosure.
- [ ] Pinned comment gives Option A and Option B in one screen.
- [ ] Each Short with a published destination uses YouTube's Related Video field; description and pinned-comment links are supporting routes only.

## Post-publish review

Record at 48 hours, 7 days and 28 days:

- impressions, click-through rate and traffic source;
- retention at 0:20, first reconstruction, reversal and verdict;
- average view duration and percentage viewed;
- A/B verdict comment share;
- subscribers gained per 1,000 views;
- approved production minutes per GPU hour;
- rerender rate by failure category.

Do not establish fixed “good” thresholds before the channel has at least four comparable uploads. Use the first month to create the channel’s own baseline.
