## Worked pilot brief

| Field | Answer |
|---|---|
| Episode ID | SA-001 |
| Working title | He Saved 2,000 Jobs by Lying to the Bank |
| Pillar | Corporate Fraud & Ethics |
| Premise | A CFO falsifies a bank covenant to preserve payroll, then the delayed collapse wipes out severance. |
| Hidden decision | Marcus signs a materially false compliance certificate. |
| Trust relationship | Workers trust management; the bank trusts the certificate; Marcus trusts the board to complete a rescue. |
| Scale | 2,000 jobs, 91 days, one missed pension contribution |
| Immediate benefit | Credit remains open and payroll clears. |
| Delayed cost | Severance disappears; lender losses deepen; pension contribution is missed. |
| Strongest defense | A truthful filing would have ended the company immediately before a credible rescue could close. |
| Strongest accusation | Marcus forced workers and the bank to finance a gamble without consent. |
| Reversal | The board hid a genuine rescue offer that would remove them; the auditor also delayed disclosure for 48 hours. |
| Earlier clue | A redacted memo timestamp appears in the first reconstruction. |
| Verdict A | Necessity: the board bears primary responsibility. |
| Verdict B | Betrayal: motive does not excuse the deliberate transfer of risk. |
| Characters | Marcus Vance, Evelyn Shaw, Elena Cruz, Daniel Mercer |
| Hero prop | White covenant certificate with brass signature line |
| Reconstruction | Credit freeze countdown → signature → payroll release → hidden offer → delayed collapse |
| Plausibility checks | Covenant mechanics, payroll timing, pension obligations, rescue-offer control terms |
| Compliance risks | Avoid instructional falsification detail; use invented entities and documents. |
| Search phrase | corporate ethics story |
| Browse promise | A lie saved 2,000 jobs—until it destroyed their safety net. |

- [ ] Case is materially distinct from identifiable real events.
- [ ] Production can fit four speaking characters and existing sets.
